# snps.se

SNPS AB:s webbplats. Statisk HTML, ingen byggkedja.

- `index.html` – framsidan
- `personer.html` – Personer
- `en/` – samma sidor på engelska (`en/index.html`, `en/people.html`)
- `styles.css`, `favicon.svg`, `img/`

Öppna `index.html` i en webbläsare för att se den, eller lägg mappen som den är på vilken webbserver som helst.

Språk: en webbläsare på svenska får svenska sidorna, alla andra får engelska. SV/EN i menyn byter språk och valet kommer ihåg. Ändras en text, ändra den på båda språken.
